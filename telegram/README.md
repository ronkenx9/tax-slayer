# 🗡️ Tax Slayer Agent

**The IRS never sleeps. Neither does your agent.**

Tax Slayer is a dual-platform (WhatsApp + Telegram) conversational AI agent built for the **OWS Hackathon 2026**. It transforms crypto tax compliance from a manual chore into a seamless chat experience.

## ✨ Features
- **Conversational Brain**: Powered by Groq (Llama 3.3 70B) for instant, human-like tax guidance.
- **On-chain Intelligence**: Real-time transaction fetching via **Moralis** and **Zerion**.
- **x402 Micropayments**: Integrated with the Open Wallet Standard for $10 USDC frictionless report generation.
- **Accountant-Ready**: Delivers CSV and PDF summary reports directly to your chat in under 60 seconds.

## 🚀 Quick Start
1. **Chat**: Start a conversation on Telegram or WhatsApp.
2. **Ask**: Get free crypto tax law guidance from our built-in knowledge base.
3. **Report**: Send your wallet address and pay $10 USDC via the x402 link to receive your full 2025 tax audit.

## 🛠️ Tech Stack
- **Engine**: Node.js, TypeScript, TSX
- **AI**: Groq SDK (Llama 3.3)
- **Data**: Moralis EVM API + Zerion
- **Payment**: x402 Protocol + MoonPay
- **Frontend**: React, GSAP, Tailwind CSS
